# Instrucciones del proyecto

- Este proyecto es una página estática de repostería en español, construida con HTML y CSS.
- Conserva el contenido visible y la interfaz en español, salvo que se solicite otro idioma.
- Mantén la estructura simple: reutiliza `index.html` y `estilos.css`; no añadas frameworks, dependencias ni herramientas de compilación sin necesidad.
- Usa rutas relativas para los recursos del proyecto y comprueba que los archivos referenciados existen.
- Conserva un HTML semántico y accesible, con metadatos dentro de `<head>` y contenido dentro de `<body>`.
- Para validar cambios, abre `index.html` en un navegador y comprueba presentación, enlaces y recursos; no hay una suite de pruebas configurada.
